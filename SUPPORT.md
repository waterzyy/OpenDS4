# Support

## Something is not working

1. Read the [troubleshooting guide](docs/troubleshooting.md).
2. Run the app from a console with `run_windows.bat --console` and collect the log.
3. Search the [issue tracker](https://github.com/waterzyy/OpenDS4/issues) for similar reports.
4. If nothing matches, open a bug report using the template and attach the log.

## Questions and ideas

Open a [feature request](https://github.com/waterzyy/OpenDS4/issues/new?template=feature_request.yml) or start a discussion in an issue. Keep in mind that OpenDS4 is intentionally offline: features that require accounts, cloud sync, or telemetry are out of scope.

## Before reporting

- Confirm that ViGEmBus is installed and the virtual Xbox 360 controller appears in `joy.cpl`.
- Try both USB and Bluetooth if one transport misbehaves.
- Include the controller model and Windows version.
