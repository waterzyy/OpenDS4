# Support

## Something is not working

1. Read the [troubleshooting guide](docs/troubleshooting.md). It covers the usual suspects: detection, ViGEmBus, Bluetooth, and startup errors.
2. Run `run_windows.bat --console` and keep the window open while you reproduce the problem.
3. Search the [issue tracker](https://github.com/waterzyy/OpenDS4/issues) for similar reports.
4. If nothing matches, open a [bug report](https://github.com/waterzyy/OpenDS4/issues/new?template=bug_report.yml) and paste the log.

## Questions and ideas

Open a [feature request](https://github.com/waterzyy/OpenDS4/issues/new?template=feature_request.yml) or just ask in an issue. Keep in mind that OpenDS4 is intentionally offline, so anything that needs an account, cloud sync, or telemetry is out of scope.

## Security

Please don't post exploitable details publicly. See [SECURITY.md](SECURITY.md).
